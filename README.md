# NØIR Sneaker Store

This repository contains the front-end implementation of the NØIR luxury sneaker house architecture. 
It relies on standard HTML5, CSS Custom Properties (Variables), and modular JavaScript for an uncompromising, high-performance architectural experience.

## Technical Requirements Fulfilled
- HTML5 Semantic Structure
- CSS Grid/Flexbox Layouts
- Custom Vanilla JavaScript Logic
- LocalStorage State Management (Shopping Cart)
- HTML5 Form Validation
- Multi-page Navigation
- Interactive 3D Model Integration (`<model-viewer>`)
- Responsive Design (Desktop, Tablet, Mobile)

## Running Locally
This project uses strictly static files. You can open `index.html` directly in any modern web browser, or use a local HTTP server to view the full experience.
